# FreeShelf — стартовый прототип

## Что уже работает
- Адаптивный каталог для экрана iPhone
- Поиск по названию
- Фильтры категорий
- Ссылки на поиск в официальном App Store
- PWA manifest и service worker для размещения по HTTPS

## Ограничение
Это веб-каталог, а не нативный установщик IPA. Веб-страница не может устанавливать произвольные приложения iOS. В ЕС собственный альтернативный магазин требует авторизации Apple, соответствия требованиям, проверки приложений и инфраструктуры. Условия для обычного личного проекта без бюджета этому не соответствуют.

## Запуск с iPhone
Самый практичный бесплатный путь — создать репозиторий на GitHub, загрузить `index.html`, `manifest.webmanifest` и `sw.js`, включить GitHub Pages в настройках репозитория, затем открыть опубликованный HTTPS-адрес в Safari. Для добавления на экран «Домой»: Safari → Поделиться → На экран «Домой».
